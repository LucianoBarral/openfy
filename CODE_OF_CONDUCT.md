# Código de Conduta

O Openfy adota o [Contributor Covenant 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/) como código de conduta. Ele vale para issues, pull requests, discussões e qualquer outro espaço do projeto.

## Em poucas palavras

- Trate as pessoas com respeito, mesmo ao discordar.
- Critique ideias e código, nunca quem os escreveu.
- Assédio, ataques pessoais, discriminação e exposição de dados de terceiros não são tolerados.

## Como relatar

Se algo violar este código, avise a manutenção do projeto de forma privada pelo perfil [@LucianoBarral](https://github.com/LucianoBarral) no GitHub, ou use a opção "Report content" na própria issue ou comentário. Os relatos são tratados com discrição.

Quem mantém o projeto pode editar ou remover contribuições que violem este código e, em casos graves ou repetidos, bloquear a participação de quem as fez.
